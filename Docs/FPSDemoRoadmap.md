## 当前入口

- 游戏默认地图设为引擎 `Entry`，默认规则为 `FPSLobbyMode`。编辑器当前地图的 PIE 仍使用当前地图规则。
- 用 `Tools/LaunchFPSDemo.ps1` 启动大厅，或启动游戏默认地图。编辑器与游戏需要使用新编译的模块；已有编辑器需保存并退出后重新启动。
- 大厅：输入 **0–9** 个人机开始单机，或进入单人靶场。单机合计最多 10 个单位，按人数平衡分队；允许 0 人机进行空场练习。
- 靶场：只建立本地游戏，有 3 个不反击的练习目标，击倒后重生；不计时结束。
- 创建房间：输入名称，由本机作为 listen server；其他玩家输入房主局域网 IPv4 地址，可加端口，默认 `7777`。同机测试使用 `127.0.0.1`。
- 房间自动分队，可在开局前切换；每队最多 5 人，双方至少各 1 人后房主可开始。满房和结算后的新连接会被拒绝。没有房间列表、自动发现、Steam/EOS 或公网穿透。
- `WASD` 移动、鼠标瞄准、左键射击（步枪/冲锋枪可连射）、`Space` 跳跃、`Esc` 菜单；新增武器键位见 `FPSWeapons.md`。普通暂停菜单不会暂停计时。房主返回大厅会关闭房间。

## 实现与边界

- `FPSMatchFlow`：新规则独立于原教学规则；单机/联机进入 LV_FPSFoundry，靶场进入 LV_FPSTraining。新增地图通过 Unreal Editor API 保存，原教学资产保留。
- `FPSFrontController`：原生 Slate 大厅和结算菜单；Esc 由 Enhanced Input 绑定。连接失败信息通过 GameInstance 跨关卡保存。
- `FPSDemoGameState`：复制等待/结束/靶场状态、服务器结束时间和最终前三名快照。对局固定 300 秒；靶场无时间限制。
- `FPSDemoPlayerState`：复制阵营；独立 ASC 和 `FPSScoreSet.Points` 使用即时 GameplayEffect 加 1，跨角色重生保留。生命仍由角色 ASC 管理。统计死亡数使用整数，因为它是比赛记录而非可叠加的战斗属性。
- 服务器拒绝友军伤害、等待房间及结算后的攻击；击倒计分、2.5 秒重生均由服务器处理。前三名按分数降序、死亡数升序、玩家 ID 升序，人数不足 3 时仅显示实际人数。
- 人机使用服务器共享平面栅格 A* 路径、胶囊净空检查与局部避让，巡逻、追踪最后可见位置并短点射；弹药不足时换弹、换副武器或寻找地面枪械。当前适配 Foundry 平面竞技场，不使用行为树/NavMesh，边界见 FPSBots.md。
- 原教学 HUD 与规则保留；PlayerState 计分内部升级为 GAS。

## 运行检查

开发版本可通过 `-FPSFlowSmoke` 在实际游戏世界中触发可重复检查，普通游戏不会执行该路径：检查队伍伤害过滤、四次服务器射击、GAS 得分、重生和冻结结算。测试时禁用人机自主攻击以稳定结果，提前触发结算以免每次等待 5 分钟；正式对局仍为 300 秒。

`FPS_SMOKE PASS/FAIL` 与 `FPS_SMOKE SNAPSHOT SERVER/CLIENT` 写入日志。快照用于核对两端的阵营、分数、死亡数和结算同步；不能替代可见窗口下的手动操作和视觉验收。

执行方法：`Tools/TestFPSFlow.ps1 -Mode LAN`、`-Mode Solo` 或 `-Mode Training`。脚本启动临时游戏进程，结束时仅关闭这些进程，不关闭已有编辑器。日志保存在 `Saved/FPSFlowTests`。

2026-09-27 本次验证结果：

- UE 5.8 Development Editor 编译及链接成功。因现有编辑器占用主 DLL，使用 `-ModuleWithSuffix=MCP_Test,9271` 构建；新启动实例通过模块清单加载该 DLL，现有编辑器不需要为这轮测试退出。
- 单机 1 人机、单人靶场、局域网 1 房主 + 1 客户端均完成实际游戏进程检查：友伤拒绝、四枪击倒、GAS +1、重生、结算快照、结束后拒绝伤害。
- 双端日志确认玩家阵营、得分、死亡数、结束状态与前三名同步；房主权限和容量边界使用真实双端加临时 PlayerState 占位检查。没有启动 10 个真实客户端进行压力测试。

## 客户端大厅初始化修复（2026-09-27）

原先通过 `GetAuthGameMode<AFPSLobbyMode>()` 判断大厅，客户端没有 GameMode，导致客户端未主动创建大厅菜单。现在由大厅使用专用 `AFPSLobbyState`，各端通过本地可见的 GameState 类型识别大厅；本地 Controller 在 BeginPlay 初始化菜单，Tick 在状态或视口尚未就绪时重试。菜单挂载到对应 LocalPlayer 的视口层。

- UE 5.8 编译及链接通过，新模块后缀为 `9272`；已经打开的编辑器需保存并重启才能加载新模块。
- `Tools/TestFPSLobby.ps1`：真实服务器/客户端进程连接大厅地图，服务器保持不操作，双方均输出完整菜单创建 PASS；客户端日志明确记录 `role=CLIENT auth-mode=0`。日志为 `Saved/FPSFlowTests/LobbyIdle-server.log` 和 `LobbyIdle-client.log`。
- 局域网对局回归：权限、容量、伤害、GAS 得分、重生及最终双端结算快照检查通过。
- 上述验证为独立游戏进程；尚未在用户现有编辑器内进行同进程多窗口 PIE 的手动验收。
