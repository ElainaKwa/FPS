## 3. 战斗 HUD：边缘信息布局

![正常战斗 HUD 去代号修订样稿](Samples/CombatHUD-v2.png)

- 顶部比分与时间，左下生命，右下武器与弹药；瞄准中心没有大面板。
- 阵营有文字与方形/三角形辅助辨识；击倒反馈在上侧短提示区域。
- 30/120、100、比分和时间只是版式占位，不指定武器或模式参数。
- 画面中的第一人称持枪属于场景示意；右下 UI 图标才是本轮轻量剪影方案。用户已明确将整体方向用于场景与武器升级，但图中的具体结构、配件和细节不是逐件复刻清单，范围以统一美术文档为准。
- 整体方向已认可；准星尺寸、角落底板面积、弹药与生命数字权重在实际视口中继续核对。

## 4. 配装：主副分栏与即时选择

![基地配装去代号修订样稿](Samples/Loadout-v2.png)

- 中央大面板保留外围战场；主、副武器分栏，右侧给选中/查看武器提供较大线稿与状态。
- `P / Esc` 关闭、基地内可更换、对局仍进行均有明确提示。
- 点击武器立即选择、成功后本局自动保存；图中没有新增二次领取、应用或保存按钮。
- 同时展示主副武器已装备标记；M4 黄色边缘表达当前焦点。后续实现需继续区分查看焦点与真实装备，不把已装备卡禁用。
- 展示部分武器并提示滚动；这不是完整武器清单。M4、M9 等线稿为示意，不保证与现有模型轮廓、配件或 HUD 小图逐处一致，接入时需由项目资产统一制作。
- 整体方向已认可；面板占屏比例、详情面积及线稿小尺寸区分度在接入时继续核对。

## 5. 本轮已检查与未验证内容

人工检查已覆盖：三图的主要中文标签、模式入口、HUD 大致锚点、武器单色表达、配装即时选择说明、无额外应用/保存按钮、非实机标识，以及三图基本视觉一致性。修订图已目视检查原代号所在的标题/预览侧栏、塔楼/箱体、墙面/旗帜区域，以及主菜单页脚；这些位置已去除代号及平台说明。已对照 [既有配装规则](../Characters/DesignDecisions.md) 记录 UI 不能改变的行为。生成编辑可能在局部纹理或笔画上产生细微差异，不声称逐像素保持不变。

本轮不修改 C++、配置、`.uasset` 或 `.umap`。静态图片不可交互，未检查鼠标命中区、焦点导航、网络权威状态、帧率、动效、实际字体字形、透明底对所有场景的可读性或 1280×800/1440p 实际运行。等待房间、暂停、结算、帮助、低血、失败与死亡状态已有设计方向，本次没有单独出图。
