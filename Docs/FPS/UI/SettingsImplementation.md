- 用途：实施与验证记录
- 适用范围：`codex/extraction-loop-lab` 的五分类设置、FPS 输入与菜单生命周期
- 状态：功能已接入；自动验证和实际采图见下文，真人听感与鼠标手感未验收
- 最后更新：2026-10-14

设计依据为 [设置设计决策](SettingsDesignDecisions.md)，使用和 UI 维护见 [设置 UI 接入](SettingsUI.md)，剩余验收边界见 [任务清单](SettingsTasks.md)。本轮基于 `dfac7af`，最终实现由本文件所在提交定位。没有纳入工作区中其他任务的 M7 资产、移动参数及其测试改动。

## 使用与保存

大厅、等待房间、对局菜单和结算的“设置”打开同一页面；搜打撤实验在工厂、行动及结算按 Esc 打开。行动背包已经打开时，Esc 先关闭背包。返回设置来源页后维持其原有输入状态。

画面修改点击“应用画面修改”才生效，切换分类保留草稿。返回时可应用、放弃或继续编辑；显示模式／分辨率变化须在 15 秒内确认。声音、控制、按键和舒适性即时生效、自动保存。每类恢复默认需再次确认。

配置保存于 Windows 当前用户的 Local AppData 下 `MCP_Test/SystemSettings.json`；由 `FPlatformProcess::UserSettingsDir()` 解析，独立于工厂存档槽。先写临时文件再替换，保存失败保留会话值并显示错误。加载保留有效旧值，缺项取默认，越界值局部恢复；旧 `UFPSInputSettings` 的疾跑／蹲伏模式作为迁移初值。显示确认期间写盘仍使用旧显示模式，防止崩溃后留下未确认的显示配置。

开发验证必须传 `-FPSSettingsProfile=<独立名称>`，重定向到 `Saved/SettingsTests/Profiles/`，避免污染玩家设置。该开关在 Shipping 中无效。

## 参数与实现依据

| 项目 | 范围／步长／默认 | 依据和边界 |
| --- | --- | --- |
| 基础 FOV | 85–100 / 1 / 92 | 保留现有 92 初值；上下限已采集 M4 腰射画面，ADS 继续读取武器 `AimFOV` |
| 鼠标灵敏度 | 0.1–3 / 0.05 / 1 | 乘现有轴响应；禁用输入平滑与引擎额外 FOV 倍率 |
| ADS 灵敏度倍率 | 0.1–2 / 0.05 / 1 | 统一乘基础灵敏度，不改变弹道、后坐力和武器放大 |
| HUD 缩放 | 0.75–1.2 / 0.05 / 1 | 对局信息面板按锚点缩放；菜单保持原尺寸，设置页提供示意 |
| 装饰晃动 | 0–1 / 0.05 / 1 | 只缩放第一人称装饰 Bob，不改控制旋转或射击方向 |
| 总音量、游戏音效 | 0–1 / 0.01 / 1 | 当前实际声音都属于游戏音效，枪声、脚步共同受控；尚无 UI／音乐内容，不提供空分类 |
| 限帧 | 30 / 60 / 90 / 120 / 144 / 165 / 240 / 不限 | 默认 120；垂直同步、动态模糊默认关 |
| 显示 | 窗口／无边框／全屏 | 默认无边框随桌面；候选尺寸来自设备查询，失效尺寸回到桌面 |
| 画质 | 低／中／高／极高及自定义 | 接入视距、抗锯齿、阴影、全局光照、反射、纹理、特效、植被；初值继承引擎已有质量配置，不强制最高 |

后台静音默认开，试听只由按钮触发。瞄准、疾跑、蹲伏默认按住，可改为切换。19 个动作各支持主、副绑定；侧键、滚轮可用，冲突需确认替换，Esc 保留，组合键和手柄不接入。帮助、交互和配装提示读取当前绑定。

`UFPSSystemSettings` 持有本机配置及显示确认；保存的两个 Widget Blueprint 由 `UFPSSettingsUI` 连接后端。`UFPSCharacterInput` 重建 Enhanced Input 上下文，方向键使用独立 Boolean 动作：引擎的“忽略按住键直到释放”仅作用于 Boolean，不能直接沿用原 Axis1D 移动映射。

阻断菜单清空移动意图、结束疾跑／瞄准和自动射击，保留物理速度、世界时间与已启动的换弹／切枪／检视／三连发。菜单阻断同步到服务器，关闭后不恢复旧按住操作。死亡等原有强制取消路径仍调用 `StopAllActions`。

## 验证边界

自动检查可以证明回调、引擎设置值、音频组件状态和实际相机值，不能替代真人听感、切后台听感或鼠标手感。仍需真人检查不同 DPI 下的灵敏度、长时间游玩、所有枪械／配件／姿态的 FOV 组合，以及完整发布包中的显示器切换。没有实现或声称验收准星自定义、手柄、DLSS／FSR／HDR／光追开关。

独立 `-game` 日志中存在引擎实验 Toolset Python 初始化的既有 `AgentSkill`／`ToolsetDefinition` 缺失报错；未影响测试断言或退出码。Cook 命令独立返回 0 错误／0 警告。没有把这些编辑器插件日志宣称为已修复。
