# FPS 系统设置设计决策

- 用途：设计决策
- 适用范围：新 FPS Demo 玩家设置、键鼠输入及阻断游戏操作的菜单
- 状态：访谈 Q1–Q27 已确认；实现与验证另见实施记录，准星自定义另行设计
- 最后更新：2026-10-14

本文记录讨论的最终决定。任务见 [实施清单](SettingsTasks.md)，当前结果见 [实施与验证记录](SettingsImplementation.md)，公共视觉遵循 [UI 设计](DesignDecisions.md)，移动基础规则见 [移动与体力设计](../Characters/MovementDesignDecisions.md)。本轮菜单中断语义以本文为准：清空操作意图不等于取消所有已启动动作。

## 范围与入口

面向玩家，包含画面、声音、控制、按键、界面与舒适性五类。不做手柄支持；开发调试独立，人机数量仍属开局配置。

大厅、等待房间、局内菜单、结算页共用设置页，现有“操作设置”升级为“设置”。左侧分类、右侧选项，中文主文案，沿用灰色／工业黄、MiSans 与 Rajdhani。以 1080p 为基准，兼顾 1440p、16:10 和 1280×800；低分辨率可在选项区滚动，保留可读文字、返回与错误提示。

局内允许调整个人设置，对局世界继续运行。退出返回来源页，Esc 每次返回一级；捕获按键时先取消捕获，不能同时退出页面。菜单不改变伤害、死亡或回合规则。

## 生效、保存和恢复

| 类别／场景 | 已确认规则 |
| --- | --- |
| 声音、控制、按键、界面与舒适性 | 即时生效并自动保存 |
| 画面 | 点击“应用”生效，切换分类保留未应用修改 |
| 显示模式或分辨率变更 | 应用后给出 15 秒确认，超时恢复此前显示设置 |
| 带未应用画面修改退出 | “应用并返回／放弃修改／继续设置”；应用涉及显示切换时仍需确认与回退 |
| 放弃画面修改 | 不回滚其他分类已即时保存的值 |
| 保存归属 | 本机系统用户一套配置，跨运行保留，无账号／云同步或多配置切换 |
| 恢复默认 | 各分类“恢复本页默认”，二次确认；画面仍需应用，其余即时生效；首版无重置全部 |
| 版本兼容 | 保留有效旧值，新增项用默认值；无效数值、失效分辨率或不可用绑定仅恢复对应项 |
| 保存失败 | 明确提示，当前会话继续使用已生效值，不假称持久保存成功 |

首次使用尽量保持当前声音和操作体验；明确指定的显示初值见下表，不自动套最高画质。滑条范围、步长、未指定初值和渲染支持情况在实施前核对并记录，不凭空填值。

## 画面

| 选项 | 规则 |
| --- | --- |
| 显示模式 | 窗口、无边框、全屏；初始无边框 |
| 分辨率 | 初始桌面分辨率；无边框跟随桌面，其余列设备支持值 |
| 帧率上限 | 30／60／90／120／144／165／240／不限；初始 120 FPS |
| 垂直同步 | 独立开关，初始关闭 |
| 画质预设 | 低／中／高／极高；修改高级分项显示“自定义” |
| 高级分项 | 视距、抗锯齿、阴影、全局光照、反射、纹理、特效、植被质量；仅展示实际支持且能生效的项 |
| 动态模糊 | 独立开关，默认关闭 |
| 基础 FOV | 默认保持当前值；安全范围结合相机和第一人称模型核定，避免露出截面 |

ADS 仍按武器规则缩放，不提供取消开镜放大选项。首版不接入 DLSS／FSR 插件、帧生成、HDR 或光追模式切换。不能凭本表假定项目已支持所有渲染选项，需记录实际可用范围。

## 声音

提供总音量、游戏音效、界面音效和音乐分类，无对应内容的分类暂不展示。枪声与脚步共同归游戏音效，不开放分别降低枪声、保留脚步的滑条。“后台静音”默认开启。

提供主动点击的试听按钮，拖滑条不连续播放枪声。初值尽量保持既有听感，实施时核对音频路由和相对响度。

## 控制与按键

提供基础鼠标灵敏度、统一 ADS 灵敏度倍率、垂直反转，以及瞄准／疾跑／蹲伏按住或切换。默认不反转，三种动作默认按住；不加鼠标平滑或加速度。不做横纵独立灵敏度或各瞄具独立倍率。

允许重绑移动、跳跃、蹲伏、疾跑、射击、瞄准、换弹、检视、切枪、丢弃、交互和配装；支持鼠标侧键与滚轮。每个动作支持主、副两个绑定，不支持 Ctrl+某键等组合键。Esc 固定用于菜单／返回，不可改绑；菜单点击等界面操作固定。

同一操作场景的冲突显示对应动作，用户选择“替换原绑定”或取消，不静默覆盖。允许清空，但提示没有可用按键的动作。捕获输入只用于绑定，不触发游戏动作。修改立即保存；关闭菜单后相关已按住的键必须松开重按，不能因新映射自动触发。帮助与操作提示应显示当前有效绑定。

灵敏度返回靶场实际试用，首版不做设置页内可玩测试场景。

## 菜单与动作生命周期

以下适用于所有阻断游戏操作的菜单，不仅是设置页。打开时清空操作意图，阻止新的角色指令且不缓存；关闭后不续接旧输入。世界与已有动作依各自生命周期推进，死亡、武器移除、模式失效等原有取消条件仍有效。

| 打开菜单时的状态 | 最终行为 |
| --- | --- |
| 移动输入 | 立即停止输入，不瞬间清零物理速度；碰撞、惯性及空中运动正常模拟 |
| 疾跑／瞄准 | 结束并清除意图，按住和切换模式均须新输入才能重入 |
| 蹲伏 | 清除意图并尝试站起；低顶受阻时保持蹲伏，空间允许后站起 |
| 跳跃 | 不接受新起跳，已离地则正常运动、落地 |
| 自动连射 | 停止继续发射 |
| 三连发 | 已启动的一组继续打完，不启动下一组 |
| 疾跑转射击准备期 | 第一发尚未发出的待发请求取消 |
| 已发出子弹／伤害 | 不因打开菜单撤销 |
| 换弹 | 不打断，正常完成，不接受新角色指令 |
| 切枪 | 已开始动作继续完成，不串接新指令 |
| 检视 | 已开始动作继续完成，不串接新指令 |

应用设置、捕获绑定等界面指令不属于角色操作指令。关闭菜单后已按住的键须释放再按，不能补发菜单期间输入。实施须核对不同菜单共用入口，避免只有设置页符合规则。

## 界面与舒适性

提供 HUD 缩放与页内示意、装饰性镜头晃动强度。晃动只调整走路起伏等装饰表现，不改变实际射击方向和后坐力规则；保留命中、受伤、弹药等必要反馈。HUD 缩放应验证不同尺寸下的提示与边界，避免遮挡准星核心区域。

用户最终明确准星自定义另行设计，本轮保持现有准星。不实施颜色、大小、RGB、形状编辑、图片导入或分享，也不新增相关配置与预览。此前访谈中有关准星自定义的建议不属于最终首版范围。

## 实施前核对与验收边界

讨论期只读调查发现 `FPSInputSettings` 已有疾跑／蹲伏模式与本地保存，`FPSInterface`、`FPSUIAssetBuilder`、`FPSFrontController` 有菜单接入，按键主要由 `FPSCharacterInput` 创建。这只是定位线索，工作区持续变化，实施前须复核；两项现有设置不代表整套系统已完成。

实施前记录 FOV 安全范围、滑条边界和初值、实际渲染支持、音频分类、输入上下文与菜单生命周期。保留无关改动及教学 Demo 行为；本地个人设置不改变服务器权威的移动、武器或伤害规则。

验收覆盖跨运行保存、显示超时回退、冲突替换和释放重按、不同菜单下动作完成／中断、死亡与切图、目标尺寸及保存失败反馈。涉及网络／GAS 的修改须观察真实服务器与客户端，不能使用编译或历史日志替代。声音听感、FOV 截面、HUD 可读性和手感须分别记录人工验收边界。
