# 配件与弹药扩展：后续方向

- 用途：未来想法
- 适用范围：模块化配件、物品弹药与搜打撤的暂缓功能
- 状态：访谈已确认方向；本文功能未纳入首次交付，尚未实施
- 最后更新：2026-10-13

来源：配件设计访谈 Q1–Q32 及最终确认。首次交付的 M4 三类配件、策划工具、训练改枪、预设和补给站已由 [设计决策](AttachmentDesign.md) 与 [任务清单](AttachmentTasks.md) 承接，不再在本文重复维护。此前关于界面生命周期、弹匣语义、弹药守恒和预设应用的未决问题已完成讨论，以设计决策为准。

## 1. 完整搜打撤与实体物品

目标玩法为搜打撤，但按阶段建设，不把本次配件设计扩成完整背包、经济、战利品和撤离系统。

- 正式玩法使用实体配件，训练模式允许自由实验；未来明确装配物品归属、消耗、拆卸去向和库存空间。
- 正式玩法通过背包中的兼容弹药堆叠供弹，枪内弹药随枪、散装备弹属于角色；训练可简化供弹，但共用换弹行为入口。
- 局外允许套用预设，待仓库系统落地后设计物品匹配、缺件反馈和原子扣除。正常游戏局内禁止套用预设的边界不因此放开。
- 完整库存、死亡掉落及撤离结算等规则尚未设计完成，实施前需单独确认。

## 2. 实体弹匣与不同弹种

首阶段弹匣仅作为容量配件。后续独立弹匣物品应保存实际装填数量，再支持按顺序混装不同弹种，逐发决定所用弹药。

用户希望未来弹种差异覆盖伤害／射程、后坐力、声音／视觉及护甲作用。具体参数计算、护甲系统、装填顺序编辑和复制／存档方案尚未确定。不得提前写成当前伤害系统已支持的功能。

不做口径转换。不同弹种或护甲作用不自动授权增加穿透、弹道或延迟补偿。

## 3. 嵌套接口与更多平台配件

未来确定需要转接座、导轨或部件提供子接口的装配关系。本轮只有平面接口，不提前建立通用装配图框架。

后续需决定父件拆卸时子件去向、级联冲突、安装顺序与库存空间，以及如何处理循环或无效依赖。平台兼容与接口匹配继续分别校验，不能把“同平台”视为所有接口均可安装。

在 M4 瞄具／枪口／弹匣完成后，再逐项扩展其他武器、握把、枪托、枪管等类别；具体型号、平台归属、资源和验收范围在相应阶段定义。不做随机词条或配件实例升级，若将来改变需另行决策。

## 4. 可切换倍率瞄具

这是明确希望增加的行为型配件，采用离散倍率档位。第一阶段先完成固定倍率／视野与参数表现型配件。

后续需设计档位、切换输入、ADS 过渡、视野与灵敏度语义、表现渲染方式，以及 GAS 动作与复制边界。不能仅修改 UI 显示倍率就宣称功能完成，也不默认引入独立画中画渲染。

## 5. 独立制作正式改枪界面

2026-10-13 用户明确要求以后单独制作，已列入 [任务清单](AttachmentTasks.md)。当前最小训练入口仅用于验证改装、换弹、取消及预设规则，不是正式界面交付；本轮不继续扩展正式布局、美术或完整交互方案。

后续界面复用已有统一解析与服务器动作接口，呈现已提交装配、候选预览、挂起换弹和拒绝原因。具体布局、模型展示、输入方式和视觉设计在独立工作中确定，不在此提前承诺新玩法。

## 6. 后续方向进入实施的条件

每项在明确玩法与依赖后更新设计决策，并建立对应任务及验收范围。本文记录方向和未决部分，不作为所有未来功能已经排期或允许立即实现的依据。
