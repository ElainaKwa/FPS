# 枪械部位伤害设计

- 用途：设计决策
- 适用范围：结构化枪械的角色命中、GAS 伤害与射手反馈
- 状态：2026-10-15 用户确认；实施与验证按配套清单推进
- 最后更新：2026-10-15

## 已确认规则

头、躯干、四肢三种区域，共用一条生命值。默认倍率分别为 2、1、0.75；不设置命中头部必死。武器引用可复用、可保存的倍率方案，首版现有结构化枪械共用默认方案，策划可创建其他方案并更改引用。

角色负责区域映射和命中体，武器方案只负责倍率，不包含骨骼名称。颈部归躯干，肩部归上臂，手脚归四肢；头部体积跟随头部轮廓，不因装饰扩大爆头范围。采用随姿态运动的独立命中体；移动胶囊继续负责移动，枪击单独查询区域。

服务器执行命中所需的姿态计算并最终裁定；玩家和人机共用 GAS 路径。每次开火时捕获基础伤害与三类倍率，命中时按 `基础伤害 × 部位倍率 × 现有模式系数` 计算，防止切枪或后续配置变化污染该次射击。原教学固定伤害路径保留。

不新增穿透：手臂挡住胸部时按先命中的手臂结算，一颗子弹只扣一次血。武器、背包和装饰不新增挡弹或减伤能力。不引入护甲、局部血量、受伤减速、弹道或延迟补偿。

爆头只增加特殊命中标记，沿用现有普通命中／击杀音效，避免叠加声音。不增加伤害飘字；标记由服务器确认实际伤害后发送，爆头致死同时保留爆头与击杀含义。

## 数据与验收边界

倍率方案是唯一可编辑来源；进入武器显式依赖集、Asset Manager 持有生命周期和内容摘要。必需方案缺失、身份冲突或数值无效阻止本局；无关错误只阻止全项目发布校验。倍率必须有限且非负，零代表该区域免疫且不产生成功伤害反馈。最终伤害保持浮点精度。

需实际验证站立、蹲伏、移动、区域边缘、四肢遮挡、世界遮挡，以及 Dedicated Server 和真实客户端扣血与反馈。没有延迟补偿，因此服务器当前姿态的判定不承诺与延迟客户端的画面逐帧一致。

实现边界、证据和未完成项见 [任务清单](HitDamageTasks.md)。
