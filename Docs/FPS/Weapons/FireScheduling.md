## 实施边界

内部 Equip 独立于 AimOff，不绑定玩家 InputID，玩家 Request 入口拒绝该命令；转移成功后仍由服务器发起装备 Ability。AimOff 只表达输入释放。

Fire Ability 将持续全自动意图与当前实例的射击周期分开。周期记录实例、模式、剩余发数和是否已经发射；模式切换不会把保持的全自动输入变成新的单发或三连发请求。松开后的三连发完成本轮，换弹/有效切枪/死亡仍中断。

空仓、换弹、举枪和跨到非自动枪时等待状态通知；射速等待使用实例 NextShotAt 截止时间，不再以 0.02 秒尝试射击。通知仅排入下一帧，避免组件原子状态修改中重入开火。各回调继续携带 R1 激活票据，Ability 结束移除订阅与计时器。

拥有者快照、动作提交/结束和实例转移触发通知；疾跑通过 CharacterMovement 的更新回调比较状态变化，仅在变化时通知。移动本身仍按引擎正常更新，并未声称全系统无逐帧工作。普通 Tick 不调度射击。

第一次射击尚未发生时，单发/三连发不能等待冷却补射；此规则也覆盖“点击先中断检视，再尝试开火”。已开始的一轮可以等待其发间隔。全自动在换弹/举枪结束后保持原输入恢复。
