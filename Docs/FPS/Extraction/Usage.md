# 搜打撤与工厂实验使用

- 用途：当前使用说明
- 适用范围：`FPSExtractionMode` 单人实验入口，不改变既有对战和训练入口
- 状态：实体格子闭环、工厂仓库操作、西侧出生东侧撤离与六类配件实战显示运行通过；回收行动不设安全区；PIE、打包与真人完整游玩未验证
- 最后更新：2026-10-16

## 启动与循环

在项目根执行 `Tools/LaunchFPSExtraction.ps1`。启动脚本使用当前 Editor 模块，进入个人工厂地图并打开行动大厅；不保存或覆盖原 `.umap`。大厅中央展示机器人与真实车间，顶部进入仓库、可走动工厂和改枪台，右下整备与出发；资金读取当前档案。沿用本项目工业灰黄美术，详细布局和资产入口见 [大厅 UI](../UI/ExtractionUI.md)。出征加载工业关隘的行动阶段，结算返回工厂大厅。`Tools/LaunchFPSFactory.ps1` 保留直接从可走动车间开始的入口。

1. 从大厅“仓库”或右下“整备”进入仓库与背包，检查 M4/M9 与配件。仓库物品可以拖入出征背包或拖回仓库；准备好后点击出发。“工厂”返回可走动车间，车间中 Tab 可再次打开大厅。
2. 行动从原来的西侧出生区进入，沿用区内有地面且无碰撞的落点选择。`WASD` 移动、鼠标射击与瞄准、`R` 换弹，沿用现有 FPS 移动和武器输入。
3. 接近物资箱并朝向它，按 `F` 拾取；`Tab` 打开、关闭背包，已打开背包时 `Esc` 先关闭。其余时候 `Esc` 打开系统设置。背包中丢弃的物资重新放到地面，可再次拾取。
4. 前往地图对面的东侧原红队出生区，按 `F` 启动 5 秒撤离。离开范围或再次按 `F` 取消，死亡导致失败。
5. 成功后全部背包物资转入仓库，结算页返回基地。材料可出售，或投入单个加工槽；完成后点击领取。
6. 将废金属加工成零件，使用零件、铜线及少量资金制作配件；在库存改装页安装到 M4，再次出征。

实验模式使用三名原有 AI 守卫，均为敌对阵营，死亡不再重生；没有五分钟对战计分结算。沿用现有导航，不声称已实现专门的搜打撤敌人生态。回收行动地图没有安全区：出生点、原蓝红基地及撤离点均可交战、受伤，敌我都可进入；撤离倒计时不提供保护。安全区文字和边界标线在本模式隐藏。

## 原型规则

上述为默认绑定，可在 [系统设置](../UI/SettingsImplementation.md) 修改。工厂和结算可按 Esc 打开设置；改枪台内 Esc 优先收起配件抽屉、返回武器概览、返回工厂。设置返回后恢复原页面。

用户确认的方向与本轮可逆实现选择区分如下：

- 已确认：单人 PvE、个人仓库；死亡只丢失本次搜获，出征枪械和已装配件保留，无维修费；复用已有地图，UI 遵循美术规范。
- 2026-10-16 用户确认回收行动不设安全区，取消地图继承的基地保护、区内禁火、跨边界射线拦截和敌方进入限制。个人工厂仍全区禁火；多人对战仍按其原有基地规则运行。验证见 [安全区取消记录](Implementation.md#取消行动地图安全区2026-10-16)。
- 本轮实现选择：5×4 出征背包、8×8 仓库；材料每堆最多 20 件、配件每堆 1 件。废金属、机械零件、瞄具占 2×1，扩容弹匣占 1×2，铜线和制退器占 1×1；旋转会交换宽高。每个堆叠保存独立 ID、数量、位置与方向，占用面积与剩余连续空间同时限制放入。
- 首版装备固定为 M4/M9，不在出征途中免费换枪、拾枪或丢枪；允许丢弃搜获物资。只在基地安装、拆卸实体配件，局内改装留待库存与换弹事务整合。既有训练模式规则保持。
- 基地枪械保留稳定实例 ID 和已提交配件；出征消耗的弹药在成功或死亡结算时保存。补给花费 10 资金，将主武器备弹补至至少 90、副武器至少 45，不减少已有备弹，不直接填满枪内弹药。
- 基地装配直接修改未部署的存档枪，不启动局内角色换弹；容量改变时只重新分配现有弹药，总数守恒。现有训练弹匣的挂起、完成、取消规则保持不变。
- 格子拖放移动整堆；拖到同型堆叠时先补满目标，多出的数量留在来源原位置。已满目标、越界或不同物品重叠会拒绝。基地用 Ctrl+左键快速互转：先合并同型堆叠，再寻找空位；空间不足则整个操作不提交。行动中只能整理本次背包，不能远程访问仓库。
- 右键点击数量大于 1 的堆叠，输入需要拆出的整数数量，点击“确认拆分”后放入当前容器的空位。原堆叠保留 ID、位置与剩余数量，新堆叠获得独立 ID；新堆叠需要连续空间，不会自动与其他堆叠合并。Esc、取消或点击弹窗外部均不改库存。只有 1 件的物品和配件不能拆分。
- 沿用“死亡仅丢本次搜获”：出征前整备背包作为快照保留。死亡或放弃后恢复该快照，新搜获丢失；主动丢出的原整备物资也随快照恢复。首版没有消耗品或局内交易，不能将此视为已完成带入物资损耗经济。成功则将当前背包全部入库并清空整备背包。
- 加工台只有一个任务，开始时扣材料和资金，完成后手动领取。产物领取与任务清除一并保存；仓库满时保留产物，不能重复领取。
- 制退器、瞄具、扩容弹匣的效果仍由现有定义资产和统一解析器计算。物品价格、配方、产出、时间及容量是实验参数，权威入口为 `FPSExtractionSubsystem.cpp`，没有额外表格副本。
- 成功撤离前检查全部搜获是否能入库；不足则整个结算拒绝，搜获仍在背包，可丢弃后重试。

## 中央改枪台

基地进入“枪械改装”后先显示武器概览：左侧选择持有的 M4 或 M9 并查看真实参数，右侧展示大幅 3D 模型。M4 点击“进入改装”后展开中央画布，瞄具、枪口、弹匣、后握把、枪托和枪管六张卡片以连线指向安装位置；点击卡片打开右侧兼容库存抽屉。M9 当前没有配件接口，仅支持浏览。

悬停装卸按钮比较参数，点击安装或卸下立即提交，屏幕模型和卡片缩略图同步变化。收起抽屉恢复大画布；Esc 逐层返回。右键拖动旋转，滚轮缩放，“重置视角”恢复当前模式的默认角度。

首次存档需搜获或制造配件；没有库存时不会免费生成配件。瞄具、制退器、扩容弹匣与后握把、枪托、枪管均从已保存的配件定义显示在工厂持枪和行动地图中。三类原配件复用现有原型网格，扩容弹匣随换弹运动与隐藏，原装弹匣和枪口被替换。当前仍是功能原型外观；实现和运行证据见 [出生与配件修复](Implementation.md#西侧出生东侧撤离与实战配件2026-10-16)。

## 存档

默认游玩启动使用 `ExtractionLab_Player_0.sav` / `_1.sav`，位于项目 `Saved/SaveGames/`。`-Profile` 参数可选择独立实验档案，名字限定字母、数字、下划线和连字符。自动测试使用唯一 `Test_日期时间` 档案，不接触默认游玩存档。

每次持久化操作先在副本上验证，再写入交替快照，写入成功才发布内存状态。加载选择有效且修订号较新的快照；v2 保存实体格子，v1 汇总库存先在内存副本中装箱迁移，下次事务提交后保存新版本，无法容纳则保留旧文件并拒绝该快照。均损坏或不兼容时保留原文件并阻止变更。保存失败反馈到界面，不能把 UI 点击当作已提交。

出征前保存行动标记；程序中断后从基地重开时视为失败，未撤离搜获不保存，装备使用出征前快照。正常死亡会保存已消耗弹药；异常退出尚无实时弹药检查点。生产结束时间使用本机 UTC，允许离线等待，不防止修改系统时钟。

不包含胸挂、保险箱、负重、武器自由拖放换装、设施等级树、共享工厂、远程玩家存档、服务器经济、实体装弹弹匣、自由建造、种田或正式发行包承诺。实际覆盖以 [实施记录](Implementation.md) 为准。
