## 阶段一：角色基础重构与区域划分

版本、职责表及逐项证据见 [第一阶段实施与验证](StageOneImplementation.md)。完成范围为 Development 编辑器可执行程序的真实独立双端、逻辑注入与渲染检查；PIE 人工游玩、专用服务器、新打包版及长时自然网络不在本次验收内。

- [x] 核对当前实现，确定生命、死亡、行动限制、模式配置及表现的职责契约；避免把 Character 原样搬进另一个大组件。
- [x] 统一目标侧生命耗尽入口与死亡通知，伤害来源不再各自负责补发淘汰；规则层负责计分与重生，角色执行身体状态变化。保留 GAS 权威、重复死亡防护和来源归因。
- [x] 区分角色通用行动限制与武器操作限制，避免移动权限依附于具体枪械库存；保留网络移动预测。
- [x] 明确相机、第一人称与第三人称表现的唯一写入方，保留现有程序动画；隔离 LV_NetSyncFPS 教学适配，保留其行为。
- [x] 建立模式规则资产与出生配装引用的基础结构；保持已有稳定武器身份、实例模型和内容校验。
- [x] 在现有地图划分两侧阵营区域、关联出生点与备用点，提供必要提示；不扩大为完整地图重制。
- [x] 针对性验收：原射击、伤害、计分、死亡、重生、移动及教学回归；新增伤害测试入口也经过统一死亡流程，重复通知不重复计分。区域位置与所属阵营可观察，提示明确保护尚未接入。

## 阶段二：配装与安全区

依赖阶段一的生命、规则与区域入口。版本、实现契约及逐项证据见 [第二阶段实施与验证](StageTwoImplementation.md)。完成范围为 Development 编辑器可执行程序的真实独立双端专项、输入/场景注入及实际渲染核对；新局初始化通过新 PlayerState 和全新进程会话验证，无缝切图、专用服务器、新打包版及长时自然网络未验收。

- [x] 实现图标/名字选枪界面与主副槽位，领取新实例并装备；对战回收旧枪，靶场保留旧实例。阶段二当时使用静态掉落；物理运动和数量上限已由第三阶段接入。
- [x] 服务器原子校验领取、库存替换与本局配装实时保存；重生按保存型号发新实例，入局初值统一，拾取/丢弃不修改选择。
- [x] 每次生命首次离区锁定选枪，返回仅恢复保护；处理界面关闭、晚到请求和旧生命请求。
- [x] 接入持续保护 GameplayEffect、来源句柄与明确 Tag；实现现有伤害/动作入口检查、区域成员及重叠处理，不误删其他保护来源。
- [x] 实现敌方通行阻止、双向攻击边界及内部禁火/禁丢；进入时清除攻击意图，离开不自动恢复射击。
- [x] 实现服务器随机有效出生、备用点及占用重试，AI 暂用默认配装。
- [x] 核对配装可选武器与本局内容依赖集：所有合法可领取武器已在开局准入/加载中覆盖，保持两端内容一致性校验；最终协议 4 的配置不一致双端拒绝回归通过。
- [x] 针对性验收：真实服务器与客户端的领取成功/拒绝、重复选择、离区竞争、重生记忆及新身份默认值；基地重返保护不重开选枪；保护来源重叠/移除、双方攻击方向、死亡与断开清理；出生碰撞和备用点场景。另在 100ms 延迟、1% 丢包下复验。

## 阶段三：物理掉落与专项联调

依赖稳定的实例转移与模式规则，不改变阶段二已确认的发枪行为。版本、实现契约及逐项证据见 [第三阶段实施与验证](StageThreeImplementation.md)。最终协议 6 的 Development 独立服务器/客户端、晚加入、100ms/1% 网络与真实 185 秒寿命专项通过；复制合并的确定性注入与自然收发场景分别记录，不替代专用服务器、新打包版或长时自然游玩验收。

- [x] 实现主动丢弃与靶场选枪替换的真实掉落，共用实例转移逻辑；当前对战替换回收、死亡不掉枪。
- [x] 实现服务器物理、客户端同步、休眠及必要的碰撞/查询设置；角色与子弹不推动或阻挡掉落枪。
- [x] 保留实例数据，空中合法拾取、双人原子认领；普通拾取自动装备规则与界面领取规则分别验证。
- [x] 实现 180 秒清理、回合动态物清理、模式数量上限和最旧物回收；用户已确认对战与靶场均 30 把，地图预置物不计入；越界直接回收及领取 0.1 秒限频通过专项。
- [x] 验收：丢拾 GUID/弹药/冷却不变；举枪不绕过原冷却；空中抢拾只成功一次；两端落地位置可用；批量领取触发上限而无实例重复或泄漏；重生不删除旧掉落；安全区禁丢不误伤靶场替换。另修复同 GUID 复制合并时的旧预测残留，并验证未改槽、失败及普通切枪不受影响。

按阶段编译并运行与改动相称的真实服务器/客户端检查，网络/GAS 不能仅凭编译通过交付。记录模块/提交、地图、模式、延迟与丢包条件、日志及未覆盖项；无法运行的部分保持待验收。测试注入与自然网络场景分开说明，不能宣称未来技能已通过测试。
