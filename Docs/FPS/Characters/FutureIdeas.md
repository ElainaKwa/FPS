# 角色与模式后续想法

- 用途：未来想法
- 适用范围：角色、美术、地图、AI 配装和后续玩法
- 状态：已记录，未纳入当前三阶段实现；具体方案待讨论
- 最后更新：2026-10-05

当前范围见 [设计决策](DesignDecisions.md) 与 [任务清单](Tasks.md)。下列项目不因为留下接口就自动获得实现或制作承诺。

| 项目 | 动机与已确认边界 | 后续需要确定 |
| --- | --- | --- |
| 角色与武器美术升级 | 当前先保留程序模型/动画，技术职责先清晰 | 骨骼模型、动画资产、Animation Blueprint、第一/第三人称资源及工作量 |
| 选枪界面视觉设计 | 当前只要求图标、名字、主副分类、点击领取，不加额外领取按钮文字 | 具体排版、图标制作、反馈风格、键鼠/手柄体验 |
| 地图扩大与大本营设计 | 当前先划分可验证的区域，完整地图应给两侧基地和交战留空间 | 尺寸、出口、掩体、路线、压出生风险及美术 |
| AI 配装与携弹量 | 未来几套配装可在出生时随机选择，不修改通用武器初始值来表达敌人差异 | 候选集、权重、每槽初始弹药覆盖与难度关系；当前仍用默认 |
| 不同形态敌人 | 共享生命/阵营/受伤契约，不强制共享人形身体与枪械组件 | 近战、飞行、炮塔各自移动与攻击行为 |
| 死斗、爆破等模式 | 每种模式一份规则资产，允许必要时增加策略代码 | 选枪/购买时机、经济、回合保枪、死亡掉落、阶段权限；当前不预设 |
| 未来负面效果与安全区 | 已确认仅阻止、不净化；效果继续计时，离开后仅剩余有效部分可生效 | 中毒、控制、强制位移等实际系统接入；不能以一个 Tag 声称全部支持 |
| 角色技能扩展 | 保留合理行为接口，继续使用 GAS | 具体技能、职业、成长与跨重生状态均未纳入 |

长期个人配装存档当前不需要；本局个人选择已在当前范围内，不混同两者。物理踢枪、布娃娃联动、受力损伤均不在本轮掉落实现中。
