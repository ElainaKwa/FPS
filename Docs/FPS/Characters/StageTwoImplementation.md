## 实现契约

| 职责 | 实现及边界 |
| --- | --- |
| 个人配装 | PlayerState 只保存主、副武器的稳定定义 ID，服务器初始化统一默认值。对战选择成功立即保存；没有个人磁盘存档、GUID 或弹药快照。靶场仍按模式默认值重生，不要求跨生命记忆。 |
| 出生发枪 | Possess 后从当前 PlayerState 选择创建新实例，新的 GUID、初始弹药及本次举枪；AI 使用模式默认值。旧枪拾取/丢弃不写偏好。 |
| 领取事务 | Controller RPC 携带实际 Pawn、本次生命 GUID 和定义 ID。服务器重新检查所有权、生命、阶段、内容准入、模式可选集与即时区域权限。创建新枪、准备旧枪处理后才取消旧动作并提交库存、装备和偏好；失败不回收旧枪或写偏好。 |
| 旧枪策略 | 对战回收；靶场复用既有静态掉落入口并保存实例数据。重力、翻滚、动态同步、30 把上限与最旧回收尚未启用，不算物理掉落完成。 |
| 选枪历史 | `UFPSBaseMembership` 持有本次生命 ID、所属出生区域和单调离区记录。每次生命首次离开即锁定；返回只恢复位置保护，不能恢复选择；旧生命请求不能改变新生命。 |
| GAS 来源 | 每个有效己方区域各持有一个无限期 `UFPSBaseProtectionEffect` 句柄，EffectContext 标注来源区域。离开或销毁只移除对应句柄，不按 Tag 清空其他来源；重叠来源不会逐帧重复授予。 |
| 保护消费 | `Character.Protection.HostileDamage/HostileControl/ForcedMovement` 表达保护；`Character.Restriction.Attack/Drop` 表达动作限制。当前实际消费者覆盖伤害、攻击和主动丢弃；控制/强制位移系统尚不存在，仅记录未来接入契约。 |
| 实际伤害 | AttributeSet 的 GAS 执行前检查阻止有明确敌对阵营来源的负 Health 修改；位置检查也覆盖 Effect 尚未施加的进入帧。正 Health 修改和自伤/环境效果不被敌对保护一概拦截；没有自动回血或净化。已有周期效果保留计时，离开后仍有效的伤害恢复执行。 |
| 攻击边界 | 当前 hitscan 在实际射线检测前裁剪到首个基地边界；对目标直接应用武器伤害也检查射手、目标与路径。双方均不能跨基地攻击，外到外途中穿过基地同样被阻断；没有实现范围技能、传送技能或未来控制系统。 |
| 攻击意图 | 进入时只取消攻击与扳机意图，不统一取消换弹、ADS、检视或切枪；离开不恢复旧连发。死亡、菜单与替换仍按各自既有取消语义处理。 |
| 通行 | 移动预测与服务器都按阵营检查整段移动和胶囊边距，防止跨越敌方基地；异常位置落入敌方区域时移到最近水平边界外。己方可自由返回。 |

当前伤害归属使用 Pawn/Controller/PlayerState，以及 Causer 的 Instigator/Owner 链；没有明确敌对阵营的环境伤害不能假冒玩家来源。将来新增伤害源需提供正确来源契约，不能仅把未知负值称为敌对影响。

## 交互和出生参数

用户本轮确认 **P** 开关选枪，**Esc** 关闭。打开后显示鼠标并暂停本地移动、视角和攻击输入，清除扳机意图；世界和其他玩家继续运行。死亡、阶段失效或离开有效区域自动关闭；不缓存本地领取结果。

界面按主、副槽位展示最小向量图标与名字，点击直接选择，显示当前库存选择和成功/失败反馈，没有额外领取按钮。图标暂按武器类别表达，美术替换与完整重映射设置界面不在本阶段内。HUD 提供 P 入口提示；教学 Controller 不接入该界面。

己方成员/首次离区检查采用 **4cm** 容差。服务器每次出生默认尝试 **32** 次区域采样（Actor 可配置 0–128）；水平边缘预留胶囊半径加 8cm。检查地面及法线、完整胶囊空间、角色中心间距大于双倍半径加 16cm。AI 额外使用现有 `UFPSBotNavigation` 检查可达路线，没有替换为 NavMesh 或制作新 AI。

采样失败后备用点走相同空间检查；仍被占用则每 **0.25s** 重试，直到有有效位置或角色断开/阶段结束。断开时清理控制器的重试句柄。靶场保留玩家和三个目标的固定出生点。

## 验证边界

本阶段尚未验收专用服务器、新打包版、十人长时自然网络、硬件逐键/手柄及音频。新局默认值通过新 PlayerState 和多次全新真实进程会话核对，没有测试无缝切图。重叠 GE 来源已运行验证；地图开局校验仍要求每队一个主出生基地，未制作多基地/嵌套区域地图方案。

部分 `-game` 日志保留既有 ExperimentalToolsets Python 初始化错误（`unreal.ToolsetDefinition` / `AgentSkill` 等属性缺失），本轮未扩展修复该插件；没有 Fatal、Assertion 或本轮专项 FAIL，不能把专项通过表述成所有日志均无错误。

阶段二当时未实现物理掉落、空中拾取、双人原子抢拾、180 秒/回合清理及模式数量上限，未自行套用靶场 30 把。用户之后确认对战也为 30 把、越界直接回收和领取间隔 0.1 秒，对应实施及验证见 [第三阶段记录](StageThreeImplementation.md)。完整输入映射资产化/用户重映射流程仍待后续细化，P/Esc 入口和本轮输入处理已经落地。
