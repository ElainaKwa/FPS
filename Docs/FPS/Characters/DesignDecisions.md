# 角色重构、配装与安全区设计决策

- 用途：设计决策
- 适用范围：新 FPS Demo 角色与模式规则；兼容原网络/GAS FPS 教学
- 状态：Q1–Q45 及第三阶段补充规则已确认；三阶段已实施，验证边界见实施记录
- 最后更新：2026-10-06

来源为角色重构讨论。本文整理最终决定，不把早期建议或静态风险当成已实现功能。任务见 [分阶段清单](Tasks.md)，实现与验证见 [第一阶段记录](StageOneImplementation.md)、[第二阶段记录](StageTwoImplementation.md) 和 [第三阶段记录](StageThreeImplementation.md)，范围外内容见 [后续待办](FutureIdeas.md)。

## 1. 目标与兼容边界（Q1–Q5）

提高扩展性、降低 Character 的职责耦合。新增伤害来源应接入统一死亡流程；更换外观不修改战斗逻辑；调整输入映射不修改角色行为。新增行为允许修改所属 C++ 模块，不要求所有功能仅靠填表实现，也不预建大量空接口。

生命与死亡入口、通用行动限制、模式规则和表现写入权应明确。武器行为继续以 GAS Ability 为核心，本地预测、服务器最终裁定；生命变化继续走 GAS。Character 保留身体与引擎生命周期职责，不要求变成纯装配空壳。具体类名、接口签名和拆分粒度由实施阶段结合当前代码确定。

玩家和持枪人形 AI 可共用身体、生命、装备与行动规则，输入和决策来源独立。其他形态通过生命、阵营、受伤、死亡等组件与能力契约复用规则，不强制继承 AFPSDemoCharacter，也不强制拥有枪械库存。炮塔、近战生物、飞行敌人本轮不实现。

死亡销毁旧角色，重生创建新角色；ASC 暂留 Character。角色临时效果和正在进行的动作随旧生命结束；阵营、得分、死亡数等对局身份由 PlayerState 持有。不新增跨重生持续的技能冷却或增益。

保留 LV_NetSyncFPS 的教学操作、内容与运行结果，允许隔离教学专用逻辑。该地图使用 FPS 角色，区别于独立的 LV_NetworkBasics 基础网络课，不要求改后者。保留现有模型与程序动画，明确第一人称、第三人称和相机各自的写入职责；美术替换另列待办。

## 2. 模式配置是规则来源（Q7–Q12、Q15–Q20、Q32–Q33）

每种玩法使用可编辑的模式规则资产，共用执行逻辑。单机/联机是运行方式，不能直接替代玩法身份。资产表达选枪阶段、立即领取或出生发放、可用武器、默认配装、死亡掉落策略和动态掉落清理规则。未来行为超出配置表达能力时增加策略实现，不堆叠无边界的布尔开关。

| 规则 | 当前五分钟对战 | 靶场 |
| --- | --- | --- |
| 选枪权限 | 每次重生后，在所属重生区域内且尚未首次离开时有效 | 始终可打开 |
| 选择生效 | 立即发放对应槽位的新实例并装备 | 同左 |
| 被替换的旧枪 | 回收，不生成掉落 | 按主动丢弃生成物理掉落 |
| 选择记忆 | 玩家各自在当前对局内实时保存 | 不要求跨重生或跨对局保存 |
| 死亡掉落 | 不掉枪，玩家与 AI 一致 | 目标默认不掉枪 |
| 主动丢弃 | 安全区内禁止，区外允许 | 允许 |

早期 Q8“死亡掉全部武器”仅作为未来启用死亡掉落策略时的已讨论方向；后续明确的当前模式规则优先，不能据此在对战或靶场启用死亡掉枪。未来其他模式是否启用需按该模式确认。

AI 当前使用默认配装，不调用玩家选枪流程或自动回基地补给。几套配装随机投放、不同敌人的携弹量细调留待后续。备弹继续属于枪实例，不改成角色共享弹药池。

## 3. 局内选择、保存与发放（Q10、Q17–Q18、Q21、Q26–Q30、Q33、Q38、Q44）

所有玩家进局使用相同的模式默认配置，随后各自在本局独立调整，不影响队友。当前默认可沿用 M4＋M9，型号由资产引用配置，不写死在 Character。保存的是各槽位武器定义选择，不是 GUID、当前弹药或冷却。重生创建新实例，弹药读取出生配装/武器定义的初始配置，不保证初始弹匣必定装满。

PlayerState 保存个人本局选择；换一局恢复模式默认，不做账号、本地个人存档或跨局偏好。主动丢弃和拾取只改变实际库存，不改变保存的配装选择。

最终规则是选枪时实时保存，已取代“离区提交”：服务器校验、发放新枪、处理旧枪和保存选择应作为一次成功操作。失败时库存和选择均不变；不得先回收旧枪后留下半完成状态。离区只关闭权限，没有待提交的候选配装。因此即使未离区就结束生命，已成功选择仍是下一次出生配置。

每次请求重新检查模式、阶段、本次生命、区域和武器合法性；不能只依赖界面开着。离区与点击接近时，以服务器处理时的有效权限为准；被拒绝的请求不能留下本地领取结果。重复选择同型号也发新实例，使用初始弹药，属于允许的区域补给。

界面分主副武器两栏，以图标和名字展示；点击哪个就发哪个，另一个槽位保持不变。不另加“立即领取”按钮文字。提供选中状态及必要失败反馈，视觉美术另行讨论，不在本轮预定完整 UI 风格。原网络/GAS 教学不接入该配装系统。

2026-10-06 用户补充确认交互：按 **P** 打开/关闭，**Esc** 关闭。打开时显示鼠标，暂停本地移动、视角与攻击输入，并清除扳机意图；世界和其他玩家继续运行。离开有效区域、死亡或对局阶段失效时自动关闭，关闭后不会自动恢复开火。

## 4. 实例转移与举枪（Q9、Q13–Q14）

主动丢弃、普通拾取替换及靶场选枪替换使用同一套实例转移规则。地面枪保留原 GUID、弹匣、备用弹药、射击冷却和后坐力恢复时间；未来实例字段也需明确转移语义。动作取消不补弹，服务器已提交的换弹结果才算生效；不恢复上一个持有者的 ADS、换弹或检视。

当前武器身份切换立即生效。武器成为手持时，新持有者开始该定义的 EquipReadyTime，准备完成前不能开火；视觉过渡独立。新举枪不能清除枪本身尚未结束的射击冷却。

普通拾取替换当前槽位时装备新枪；进入非当前槽位时保持原手持武器；没有手持武器时自动装备。非当前槽位不会提前进行举枪。切枪和拾取不自动开镜。选枪界面是明确例外：领取后直接装备所选新枪，即使选择的是另一个槽位。

## 5. 两侧大本营与出生（Q28–Q29、Q31、Q34–Q39）

地图设置阵营大本营区域 Actor，出生点明确关联所属区域。服务器在区域内采样出生位置，检查地面、胶囊空间及角色间距；AI 额外检查导航可达性。有限次失败后使用配置的备用点；备用点也无效或被占用则短暂等待重试，不强行挤入墙体或角色。

每次生命只授予所属出生区域的选枪权限，第一次离开后锁定到下一次重生；返回、进入其他区域或重叠区域不重新授予。边界有少量容差，具体值由实施验证决定。离开时关闭界面，服务器拒绝后续领取。

允许返回己方大本营恢复保护，但不恢复选枪。保护按当前位置判断，配装权限按本次生命历史判断。接受玩家返回基地避战这一玩法结果，不新增单向出口。

敌方角色不能进入己方基地，攻击双向不得穿越基地边界；内部禁止开火和主动丢枪，允许移动、换弹、ADS、检视和切枪。角色通行按阵营判定，攻击阻断不靠阵营放行。范围伤害检查目标保护；外部射向外部、途中穿过基地的攻击也必须被阻断。未来技能、传送等需接入同一规则，本轮仅实现当前存在的路径，不宣称已支持所有未来技能。

本轮先划分区域、做最小必要的边界提示与备用出生点，再分阶段完善功能。地图扩大与美术路线设计另列待办，不把区域放置等同于安全区已生效。

## 6. GAS 安全区保护（Q36、Q40–Q43）

用持续 GameplayEffect 授予明确的多个保护/限制 Tag，分别表达免伤、免疫敌对控制/强制位移、禁止攻击、禁止主动丢弃等。具体命名由实现确定。伤害、控制、位移和动作入口实际消费这些状态；添加 Tag 本身不等于实现拦截。

区域管理通行、攻击边界和成员关系；Buff 管理角色保护与行动限制。服务器确认进入有效己方安全区后施加，离开最后一个有效区域后移除该保护来源持有的 Effect。处理重叠来源，不逐帧反复发放，不清空其他来源的免伤 Tag。客户端展示状态，服务器最终裁定。

仅阻止敌对影响，不自动净化或回血。已有持续伤害效果继续计时，但区域内伤害不生效；敌对控制区内不得继续限制角色，离开后仅在原效果仍有效时恢复。这个未来效果契约需后续控制系统支持，不为尚不存在的中毒、击退等提前实现整套功能。友方治疗不因安全保护一概禁止。

进入安全区立即取消当前攻击并清除持续扳机意图，离区后须重新按下；不能在退出时恢复进入前的连发。其他允许动作不因此全部取消。主动丢弃限制与配装替换策略区分，不能误伤靶场领取造成的旧枪掉落。

## 7. 物理掉落与拾取（Q12、Q22–Q25）

动态掉落具备重力、场景碰撞、翻滚和落地静止。主动丢弃从安全位置向前轻抛，继承适量角色速度。若未来模式启用死亡掉落，从武器附近释放，继承速度并加少量分离冲量；当前两种模式不触发该路径。不新增布娃娃联动或物理损伤。

武器与场景地面、墙体发生物理碰撞；角色只对它作查询/触发检测，不被阻挡、不踢动它；子弹不与掉落枪发生物理交互，也不能把枪作为掩体。物理姿态不改变实例数据。

服务器决定物理状态和归属，客户端展示同步结果；休眠后减少无意义同步。空中也可在合法距离内主动拾取，不自动吸入背包。服务器原子认领，双人抢拾不能产生两个库存实例。敌我均可拾取，无归属锁。

重生不删除已丢出的旧枪，新发枪与旧枪是不同实例。动态掉落保留 180 秒寿命，回合结束清理本回合动态掉落；地图武器台保持原规则。模式资产配置动态掉落上限，靶场默认 30；超出时回收最早生成、仍未被拾取的动态掉落，预置武器不计入，并告知玩家该限制。2026-10-06 用户补充确认当前对战上限也为 **30**，其他未来模式仍须单独确定。

2026-10-06 用户补充确认：动态掉落越过世界有效边界或低于地图 KillZ 时直接回收，不自动恢复到最后位置或玩家附近。选枪领取请求每位玩家最短间隔 **0.1 秒**，过快请求拒绝并反馈，库存与配装不变；该限频不延迟成功请求的即时发放。

## 8. 尚未定稿的实施细节

本轮确认的是以上规则，不代表所有角色设计分支已讨论完。P/Esc 交互、死亡归因、当前区域异常位置、物理越界回收及当前两模式上限已在实施中明确；完整输入重映射流程、其他区域嵌套方案和未来模式策略仍需设计或核对。常规可逆技术细节可自行决定；影响玩法或扩大范围的分歧应先澄清。

未来爆破的购买、保枪、回合阶段以及新死斗的具体配装方案尚未确认，不能仅凭“模式可配置”就实现这些玩法。
