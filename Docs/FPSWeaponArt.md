# 第三阶段 A：独立枪械模型

2026-09-28 制作六种原创低多边形静态网格：AK、M4、MP5、UMP45、M9、Heavy Pistol。按武器类别和轮廓简化建模，不是厂商授权的精确复刻。

- AK：木质护木/枪托、弯弹匣和上置导气管。
- M4：沙色护木/弹匣、顶导轨和伸缩式枪托轮廓。
- MP5：圆形机匣、紧凑护木、伸缩杆枪托和弯弹匣。
- UMP45：方形聚合物机匣、镂空枪托和直弹匣。
- M9：较短套筒、小口径枪口和黑色握把。
- Heavy Pistol：加长宽套筒、大口径枪口和沙色握把。

网格位于 `/Game/FPSDemo/Weapons/Meshes/SM_WP_*`，使用金属、钢、聚合物、木质、沙色和瞄准标记材质。源文件位于 `ArtSource/FPSDemo/Weapons`，通过 `python Tools/generate_weapon_models.py` 可重新生成 OBJ/MTL；`manifest.json` 记录几何统计与枪口/瞄具坐标。单位为厘米，+X 为枪口方向，+Z 为上方。资源通过 Unreal StaticMeshTools 导入，不直接修改二进制资产。

武器定义引用各自网格；第一人称、第三人称及拾取外观使用相同型号。新增 `MuzzleLocation` 和 `SightHeight` 配置用于枪口闪光及机械瞄具对齐；开镜时显示枪体，取消上一阶段隐藏占位枪体的处理。手枪使用独立持枪偏移。打包配置加入该资源目录，避免运行时拼接的软引用被 Cook 遗漏。

本批仍使用整枪静态网格和已有程序动画，尚未拆分可动弹匣/枪机、制作角色手臂骨骼动画、原创声音和新地图。模型无纹理贴图，材质采用纯色；后续可在保留材质槽的基础上细化。

本轮编译通过（模块后缀 `9281`），资源已在编辑器导入和保存。按用户要求未继续 PIE、联机或自动化游戏测试，持枪/开镜效果仍需之后进行游戏内视觉验收。当前打开的编辑器若仍加载旧 DLL，需要重启后使用本次代码。
