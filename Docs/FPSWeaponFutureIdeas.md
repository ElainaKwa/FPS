# 武器与人机：待拓展想法

状态：**讨论记录，非本轮必做范围，未实现。** 当前承诺见 [设计决策](FPSWeaponRefactorDecisions.md)，当前任务见 [待改清单](FPSWeaponRefactorChecklist.md)。不要为这些想法提前加入空实现、无消费字段或无效枚举项。

## 1. 逐发装填（Q26、Q29、Q30、Q35）

用户明确暂缓实现，也暂不新增用于验证的霰弹枪或逐发装填测试定义。本轮只实现独立弹匣换弹 Ability，并将弹药提交集中到清晰的服务器接口。

未来需要表达的阶段：开始 → 每发装填循环 → 是否继续 → 收尾。每完成一轮，由服务器提交一发弹药；已经完成的装填不因之后中断撤销，未完成的一发不计入。

已接受的未来规则：

- 已有弹药时允许通过开火请求中断逐发装填，未完成的一发不计数。
- 经过可配置收尾准备时间后开火；有效切枪仍可立即中断。
- 与本轮弹匣换弹“禁止开火打断”不同，作为换弹行为差异表达，不全局放开限制。
- 未来新增逐发装填 Ability，可复用弹药提交和校验接口，不要求重写角色、拾取或伤害系统。

未来仍需细化：首发/后续装填时长、满弹收尾、按住扳机的请求处理、收尾期间再次取消、预测纠正与动画同步。现在不把这些细节当作已定方案。

## 2. 难度影响人机攻击行为（Q31、Q33）

用户希望难度最终不仅改变伤害，还能改变攻击行为。本轮为控制工作量，只实现预设伤害倍率：简单 0.5、普通 0.65、困难 0.85。

未来可讨论反应时间、瞄准误差、点射节奏、目标选择、接敌距离等参数。它们属于 AI 决策/难度配置，不直接混入武器型号定义；AI 仍使用共用 Ability，不能通过难度绕过武器的权威射速和动作限制。

具体参数、组合及平衡目标未定；“更难”不应被实现者自行等同于完美瞄准或透视追踪。

## 3. 动态难度与情境伤害（Q31、Q32）

用户认为预设、自适应、情境修正三种方向都值得考虑；当前只采用预设。

未来讨论方向：

- 对局自适应：根据玩家近期表现调整难度；观察窗口、变化速度、上下限与是否向玩家说明尚未确定。
- 情境修正：距离、剩余生命、连续受击等条件是否影响伤害；触发条件与叠加顺序尚未确定。
- 多个修正同时存在时的组合、优先级、快照时机和可调试性。

已定边界：倍率由服务器规则提供，仅作用于人机攻击玩家；不写入枪械实例。玩家拾取人机枪械后正常伤害，人机互打也默认正常伤害。继续通过共用 GAS 伤害流程结算。

## 4. 设置菜单接入

未来菜单可暴露“换弹保持开镜 / 开始换弹退出一次”选项。本轮只实现并验证行为选项，不制作设置页面。默认保持开镜；退出模式需松开右键再按才能重新开镜，换弹期间仍允许进入开镜，服务器执行一致规则。

这不是“切枪后自动开镜”设置：本轮切枪后明确不自动恢复开镜。
